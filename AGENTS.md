# Learning DSP in modern C++

This project is for learning digital signal processing (DSP) in modern C++ using SOLID, domain-driven design (DDD), object-oriented (OO) design, and test-driven development (TDD).

Follow the learning checklist in [ROADMAP.md](ROADMAP.md). Keep implementations and tests tied to audio use cases.

Use the shared test suite on macOS and supported embedded targets as described in [TESTING.md](TESTING.md).
